# kelvin-to-rgb-visualizer

A tool to convert Kelvin temperature to RGB and HEX color codes, visualizing the corresponding lighting effects.

**Description:**

This project provides a way to understand the relationship between color temperature (in Kelvin) and the resulting RGB and HEX color values. It allows users to input a Kelvin temperature and see the corresponding color representation, simulating the appearance of light at that temperature.

**Features:**

*   **Kelvin to RGB Conversion:** Converts a given Kelvin temperature to its corresponding RGB color value.
*   **HEX Code Generation:**  Displays the HEX code of the calculated RGB color.
*   **Visual Representation:** Provides a visual representation of the color, allowing users to see the lighting effect.

**Getting Started:**

**Prerequisites:**

*   Node.js
*   npm

**Installation:**

1.  Clone the repository:

    ```bash
    git clone https://github.com/marufx86/kelvin-to-rgb-visualizer.git
    ```

2.  Navigate to the project directory:

    ```bash
    cd kelvin-to-rgb-visualizer
    ```

3.  Install dependencies:

    ```bash
    npm install
    ```

**Running the App:**

```bash
npm run dev
```
Open your browser to http://localhost:8080/ to view the app.

**Deployment:**

The app is deployed on Vercel at [https://kelvin-to-rgb-visualizer.vercel.app](https://kelvin-to-rgb-visualizer.vercel.app/).  To deploy your own version:

1.  Push your code to GitHub
2.  Import the repository to Vercel
3.  Deploy
